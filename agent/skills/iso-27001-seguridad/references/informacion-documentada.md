# Información documentada obligatoria

- **Mantener** = documento vivo, con control de versiones.
- **Conservar** = registro/evidencia, protegido contra modificación, con retención definida.

## Checklist de control documental (§7.5.2 y §7.5.3)

- [ ] Identificación única, versión, fecha, autor, **clasificación de la información**.
- [ ] Revisado y aprobado antes de emitir; evidencia de aprobación.
- [ ] Versiones obsoletas retiradas o identificadas.
- [ ] Disponible para quien lo necesita, **restringido para quien no** (el propio SGSI es información a proteger: la SoA y el registro de riesgos suelen ser confidenciales).
- [ ] Protegido en integridad (historial de cambios, permisos, respaldo).
- [ ] Documentos externos controlados (normas, requisitos legales, documentación de proveedores).
- [ ] Registros con retención y disposición definidas (coherente con 5.33 y 8.10).
